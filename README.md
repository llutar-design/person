# 인물탐험대

초등학교 2학년이 혼자 인물을 탐험하며 배우는 웹앱입니다.
한국을 빛낸 인물 100명과 세계를 빛낸 인물 100명의 이야기를 읽고(듣고), 퀴즈를 풀고, 작은 실천 미션을 하며 탐험 도장을 모읍니다.

학습 흐름: 인물 선택 → 이야기 4장면 → 퀴즈 3문제 → 실천 미션 → 탐험 도장 (인물당 약 5~7분)

## 바로 실행

- 설치나 빌드가 필요 없습니다. 저장소를 내려받아 `index.html`을 브라우저로 열면 됩니다.
- **GitHub Pages로 공개하기**: 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 정하고 저장합니다. 잠시 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 열립니다.
- GitHub Pages(https)로 열면 오프라인 기능이 켜져, 한 번 본 화면과 그림은 인터넷이 끊겨도 볼 수 있습니다.
- 제목 글꼴(Jua)만 인터넷에서 불러옵니다. 없어도 기본 글꼴로 모든 기능이 동작합니다.

## 주요 기능

- 한국 100명 · 세계 100명, 이름 검색과 분야별 탐색(과학·발명, 문화·예술, 나라와 사회, 배움과 생각, 나눔과 인권)
- 이야기 4장면: 어떤 사람이었을까? / 어떤 어려움을 만났을까? / 무엇을 했을까? / 오늘 우리는 무엇을 생각해볼까?
- 어려운 낱말 풀이, 읽어주기(브라우저 음성 합성, 미지원 기기는 읽기로 학습), 글자 크기·읽기 속도 조절
- 퀴즈: 틀리면 고른 답을 잠그고 점점 쉬운 힌트, 맞히면 해설. 벌점·시간 제한 없음
- 실천 미션('나중에 해볼래요'도 완료 인정), 탐험 도장, 함께 탐험하면 좋은 인물 추천
- 탐험대원 번호(1~30번): 한 기기를 여러 학생이 쓸 때 기록을 따로 저장(이름 수집 없음)
- 기록 코드: 다른 기기로 도장 옮기기
- 선생님·보호자 안내: 인물 선정 기준, 동요 '한국을 빛낸 100명의 위인들'과의 차이, 인물별 참고 자료와 검토 메모

## 콘텐츠에 대해 (꼭 읽어 주세요)

- 인물 이야기·퀴즈는 **AI가 작성한 초안**이며 모두 `검토 필요` 상태입니다. 수업에 쓰기 전에 앱의 '선생님·보호자' 화면에 있는 참고 자료(한국민족문화대백과사전, NobelPrize.org, 브리태니커 등)와 대조해 주세요.
- 인물 이름은 한국 인물은 한국민족문화대백과사전 표제어, 세계 인물은 국립국어원 외래어 표기 용례를 기준으로 확인했습니다.
- 인물 그림은 모두 AI로 만든 **상상 그림**이며 실존 인물의 얼굴은 그리지 않았습니다. 화면에 "상상해서 그린 그림이에요"라고 표시됩니다.
- 동요 가사는 싣지 않았습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html`, `css/`, `js/app.js` | 화면과 학습 흐름 |
| `data/people-korea.js` | 한국 인물 100명 (+ 동요에서 제외한 인물과 사유 `SONG_EXCLUDED`) |
| `data/people-world.js` | 세계 인물 100명 |
| `images/` | 화면 그림(`ui/`), 아이콘(`icons/`), 인물 대표 그림·썸네일·장면 그림(`people/<인물ID>/`) |
| `manifest.webmanifest`, `sw.js` | 앱 설치·오프라인 지원 |
| `docs/이미지_만들기_목록.txt` | 인물 대표 그림을 만들 때 쓴 프롬프트 |
| `tools/` | 데이터 검사·자동 테스트 도구 |

## 콘텐츠 고치기

- 인물 데이터는 `data/*.js`에 있습니다. JSON 문법(큰따옴표, 끝 쉼표 없음)을 지켜야 합니다.
- 인물마다 `scenes`(4장면 × 2~3문장), `glossary`(낱말은 본문에 그대로 있어야 함), `quiz`(3문제, `answer`는 선택지 번호 0부터, `hints` 2개, `explanation`), `mission`, `sources`, `reviewNote`가 있습니다.
- 사람이 출처와 대조해 확인한 인물은 `"status": "검토 완료"`로 바꿉니다.
- 장면 그림은 `"sceneImages"`(장면 4개에 맞춘 배열, 그림이 없는 장면은 `null`)로 연결합니다.

## 검사

```
python tools/validate.py              # 명단 수, ID 중복, 내용 누락, 그림 파일 확인
python tools/test_server.py 8766      # 테스트용 서버 (다른 창에서 실행)
# 브라우저로 http://127.0.0.1:8766/tools/selftest.html    → 화면 흐름 자동 테스트
# 브라우저로 http://127.0.0.1:8766/tools/mobilecheck.html → 360px 화면 검사
```

`tools/slice_images.py`는 여러 그림을 한 장에 모은 이미지를 잘라 내는 도구입니다(Pillow 필요).
